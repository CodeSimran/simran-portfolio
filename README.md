# ⚡ Simran Kumari — Full Stack Developer & Technical Mentor

> Modern, interactive personal portfolio website showcasing full-stack engineering projects, technical mentorship experience, algorithmic problem solving, and a real-time Admin Content Management System.

---

## 🌟 Key Features

- **🎨 Modern Humanized Design & Micro-Interactions**:
  - Interactive Cursor Image Trail effect on hero hover.
  - 3D Holographic Glare CV Card with dynamic tilting and depth layers.
  - Responsive layouts tailored for high-end aesthetic appeal across all devices.

- **📄 Dynamic CV & Resume System**:
  - Direct 1-click PDF download & preview triggers.
  - Supports direct local PDF file uploads and Google Drive integrations with live synchronization across Navbar, Hero, and Footer.

- **🛠️ Built-in Real-Time Admin Manager (`/admin`)**:
  - **Project Management**: Add, edit, reorder, delete projects, and upload custom thumbnails.
  - **Resume Config**: Direct CV PDF uploader, Google Drive link auto-extractor, custom status badges, and metadata settings.
  - **Zero Authentication Friction**: Instant access for quick customization.
  - **Shortcut**: Toggle admin panel anytime using `Ctrl + Shift + A` (or `Cmd + Shift + A`).
  - **Code Backup & Export**: 1-click export of current configuration to Git data files.

- **💼 Featured Sections**:
  - **Hero & 3D CV**: High-impact introduction with interactive 3D document card.
  - **Experience**: Engineering and technical mentoring track record.
  - **Projects Showcase**: Filterable, interactive project cards with live demo and GitHub repository links.
  - **Achievements & Metrics**: Competitive programming milestones (LeetCode Top 5%, 500+ problems, CGPA 9.60).
  - **Skills Matrix**: Core proficiencies across Frontend, Backend, Databases, and DevOps.
  - **Contact**: Direct messaging and social connect links.

## 🚀 Getting Started Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/CodeSimran/simran-portfolio.git
   cd simran-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   - Portfolio Site: `http://localhost:5173/`
   - Admin Manager: `http://localhost:5173/admin` (or press `Ctrl + Shift + A`)

---

## 📦 Production Build

To generate the optimized production bundle:

```bash
npm run build
```

The output will be created inside the `dist/` directory, ready to be deployed to **Vercel**, **Netlify**, or **GitHub Pages**.
